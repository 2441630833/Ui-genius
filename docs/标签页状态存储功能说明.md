# 标签页状态存储功能说明

## 功能概述

该功能实现了自动保存和恢复用户最后访问的标签页，当用户重新打开应用时，会自动切换到上次访问的标签页，提升用户体验。

## 功能特性

- ✅ 自动保存当前访问的标签页状态
- ✅ 应用启动时自动恢复到上次访问的标签页
- ✅ 支持所有标签页（intro、dashboard、design、editor）
- ✅ 错误处理和日志记录
- ✅ 模块化设计，便于维护

## 实现原理

### 1. 核心工具模块 (`common/tabStorage.js`)

提供了标签页状态管理的核心功能：

- `saveCurrentTab(pagePath)` - 保存当前标签页状态
- `getLastTab()` - 获取上次访问的标签页
- `restoreLastTab(delay)` - 恢复到上次访问的标签页
- `clearTabState()` - 清除标签页状态
- `isTabPage(pagePath)` - 检查是否为标签页

### 2. 应用级别管理 (`App.vue`)

在应用的生命周期中管理标签页状态：

- `onLaunch` - 应用启动时恢复标签页
- `onShow` - 应用显示时恢复标签页
- `onHide` - 应用隐藏时保存当前标签页
- `onTabItemTap` - 标签页切换时保存状态

### 3. 统一状态管理

所有标签页状态的保存和恢复都在 `App.vue` 中统一管理，避免重复代码和潜在的状态冲突。各个标签页专注于自己的业务逻辑，不需要关心状态存储。

## 使用方法

### 基本使用

功能已自动集成，无需额外配置。用户在使用应用时：

1. 切换到任意标签页
2. 关闭或最小化应用
3. 重新打开应用时，会自动回到上次访问的标签页

### 开发者使用

如需在代码中手动管理标签页状态：

```javascript
import { saveCurrentTab, restoreLastTab, getLastTab, clearTabState } from '@/common/tabStorage.js'

// 保存当前标签页
saveCurrentTab('pages/dashboard/dashboard')

// 恢复到上次标签页
restoreLastTab()

// 获取上次访问的标签页
const lastTab = getLastTab()

// 清除标签页状态
clearTabState()
```

## 存储机制

- **存储方式**: 使用 `uni.setStorageSync()` 进行本地存储
- **存储键名**: `lastTabPage`
- **存储内容**: 页面路径字符串（如：`pages/dashboard/dashboard`）
- **数据持久性**: 数据会持久保存，直到用户清除应用数据

## 支持的标签页

- `pages/intro/intro` - 介绍页
- `pages/dashboard/dashboard` - 仪表板页
- `pages/design/design` - 设计页
- `pages/editor/editor` - 编辑器页

## 错误处理

- 所有操作都包含 try-catch 错误处理
- 错误信息会输出到控制台
- 即使出现错误也不会影响应用正常运行

## 性能优化

- 使用延迟执行避免应用启动时的冲突
- 检查当前页面避免不必要的页面切换
- 轻量级存储，不影响应用性能

## 调试信息

功能运行时会在控制台输出相关日志：

- `已保存标签页状态: pages/xxx/xxx`
- `已恢复到上次访问的标签页: pages/xxx/xxx`
- `标签页切换，已保存状态: pages/xxx/xxx`

## 注意事项

1. 功能依赖 uni-app 框架的 `uni.setStorageSync()` 和 `uni.switchTab()` API
2. 仅在标签页之间切换时生效，非标签页不会被保存
3. 应用首次启动时，如果没有保存的状态，会保持默认行为
4. 建议在生产环境中关闭调试日志
